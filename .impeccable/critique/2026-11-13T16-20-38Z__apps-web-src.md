### Priority Issues

- **[P0] Mandatory Login Wall Blocks Public Rankings on Load**
  - **Why it matters**: `TopFoodShell.tsx:78` initializes `showLoginScreen = true`, hiding the rankings on `/`, `/topfood/timisoara`, and `/topdrink/timisoara` until the user clicks `"Explorează fără cont"`. First-time visitors and SEO crawlers hit an auth gate instead of Timișoara's #1 spots.
  - **Fix**: Default `showLoginScreen` to `false` in `TopFoodShell.tsx`; open `LoginScreen` only from `"Intră în cont"` in `Navbar.tsx` or when triggering a gated action (`Scrie un review`).
  - **Suggested command**: `/impeccable onboard`

- **[P1] Mobile Map Split-Screen Squeeze & Bottom Nav Occlusion**
  - **Why it matters**: At 375px width, `MapView.tsx:498-507` renders a 320px sidebar (`w-80`) beside the `flex-1` map, crushing both panes. Worse, the fixed mobile bottom `Navbar` occludes the selected venue preview card's `"Deschide fișa localului"` CTA, intercepting taps.
  - **Fix**: Default `sidebarOpen` to `false` on `< md` viewports (using a toggleable bottom sheet), add `pb-20` / `bottom-16` clearance above the fixed mobile bottom nav across `MapView`, `MonthlyTopView`, and `EditorialListView`, and replace the `border-l-4` (`side-tab`) on selected sidebar rows with a subtle background fill + badge.
  - **Suggested command**: `/impeccable adapt`

- **[P1] No URL/Route Sync, Missing Search on `topdrink`, and Stale `<title>`**
  - **Why it matters**: Switching between `topfood`/`topdrink` or `Top`/`Hartă`/`Luna asta` in `TopFoodShell.tsx` only updates React state—users cannot share links or use browser Back/Forward, `/topdrink/timisoara` retains the `topfood` `<title>`, and `EditorialListView.tsx` omits the search bar on `topdrink`.
  - **Fix**: Sync `vertical` and `navSection` with Next.js routing, set per-route `<title>` metadata on `/topdrink/timisoara`, and share the search input across both `topfood` and `topdrink`.
  - **Suggested command**: `/impeccable harden`

- **[P1] Hardcoded Light Surfaces, Dark-Mode Contrast Failures, and Modal Ghosting**
  - **Why it matters**: `MapView.tsx` floating overlays (`lines 1131, 1140, 1170, 1209`) hardcode `bg-white text-[#3A2418]` in `topdrink` and Dark Mode; 538 hex values bypass `globals.css` tokens; dark-mode saved-venue links in `Navbar` popover and unselected filter tags fall below WCAG AA contrast; `RestaurantDetailModal` ghosts background text during `modal-backdrop-enter`.
  - **Fix**: Migrate hardcoded hex colors to CSS custom properties in `globals.css`, give `RestaurantDetailModal` a solid opaque panel background separate from the backdrop, and fix dark-mode link/tag contrast.
  - **Suggested command**: `/impeccable colorize`

- **[P2] Keyboard, ARIA, and Touch-Target Accessibility Gaps**
  - **Why it matters**: SVG pins (`MapView.tsx:1025`) and 300m rings (`897`) are `<g onClick>` with no keyboard access; icon-only buttons (`MapView.tsx:598, 1178, 1235`) lack `aria-label`; `EditorialListView.tsx:554` Vibe Check modal lacks `role="dialog"`, `aria-modal`, and `Escape`; `Navbar.tsx:157-215` popover lacks `aria-expanded`, `Escape`, and outside-click dismiss; `BrandWordmark` & `MonthlyTopView` podium buttons strip focus outlines (`focus:outline-none`); multiple controls are `< 44×44px` (`Navbar` `36px` buttons, `16px` popover close, `28px` modal close, `14px` clear-search).
  - **Fix**: Add `tabIndex={0}`, `role="button"`, `aria-label`, and `Enter`/`Space` handlers to map pins/zones; add proper dialog/popover ARIA & focus trapping; remove `focus:outline-none` and ensure `min-w-11 min-h-11` tap targets on mobile.
  - **Suggested command**: `/impeccable audit`
